# SK가스 전결규정
- 개정번호: 35차 / 개정일자: 2026.02.11
- 분류번호: II-조직-10

## 표시기호 및 결재 구조
- **●결정**: 해당 직급이 최종 전결권자 (그 아래 모든 직급 경유 후 해당 직급에서 최종 결재)
- **○보고**: 결재 없이 보고만 필요
- 결재 직급 순서(낮음→높음): 팀장 → 실장/담당 → 본부장 → 대표이사 → 이사회

**예시 해석:**
- 본부장 ●결정 → 결재선: 팀장 → 실장/담당 → 본부장
- 대표이사 ●결정 → 결재선: 팀장 → 실장/담당 → 본부장 → 대표이사
- 이사회 ●결정 → 결재선: 팀장 → 실장/담당 → 본부장 → 대표이사 → 이사회

### 5. 운영예산

#### 5.1. 운영예산 편성
- 5.1.1. 운영예산 편성지침 통보/편성통보 → **본부장** ●결정, 이사 ○보고
- 5.1.2. 운영예산 확정 → **이사회** ●결정
- 5.1.3. 확정예산 및 운영지침 통보 → **본부장** ●결정

#### 5.2. 운영예산 변경
- 5.2.1. 관리가능고정비 변경
  - 일반관리 Group 계정과목 증액:
    - 3,000만원 이하 → **팀장** ●결정
    - 3,000만원 초과 ~ 1억원 이하 → **본부장** ●결정
    - 1억원 초과 → **대표이사** ●결정
  - 일반관리 Group 계정과목 간 이체:
    - 3,000만원 이하 → **팀장** ●결정
    - 3,000만원 초과 ~ 1억원 이하 → **본부장** ●결정
    - 1억원 초과 → **대표이사** ●결정
  - 중결관리 Group 계정과목 증액(총금액) → **대표이사** ●결정
  - 중결관리 Group 계정과목 간 이체(총금액) → **본부장** ●결정
  - ※ 상기 계정과목 Group은 첨부1-1 증액 Grouping 리스트 참조
  - ※ 최종승인인자의 최하위자에 해당하는 운영예산 관리 조직장 참조 필요
    - 전결자: 대표이사 → 협조자: 전략본부장, 최적화실장, 경영분석팀장
    - 전결자: 본부장 → 협조자: 최적화실장, 경영분석팀장
    - 전결자: 실장 → 협조자: 경영분석팀장
- 5.2.2. 조직간 이체 → **본부장** ●결정
  - ※ 전결자: 예산신청 실장/담당(지사장/지지장)
  - ※ 협조자: 예산보유 실장/담당(지사장/지지장), 경영분석팀장

#### 5.2.3. 기간 예산 이체 → **본부장** ●결정
- ※ 협조자: 경영분석팀장

#### 5.2.4. 예산 갈액 → **대표이사** ●결정
- ※ 협조자: 경영분석팀장

#### 5.3. 예산집행
- 1,000만원 이하 → **팀장** ●결정
- 1,000만원 초과 ~ 3,000만원 이하 → **실장/담당** ●결정
- 3,000만원 초과 ~ 1억원 이하 → **본부장** ●결정
- 1억원 초과 → **대표이사** ●결정
- ※ 단, 일부 계정은 회계전표 승인으로 대체하며, 구매관리에 해당되는 사항 발생 시 구매관리규정에 따름 (첨부1-2 계정별 집행전결권한표 참조)
- ※ 타 팀 예산사용 시 사전협의 및 사후 전표통제 필요
- ※ 영업외비용 중 기부금 항목은 본 기획관리 전결권한표 적용함

## 첨부3. 재무관리 공통 전결권한표
단위금액: 천원

### 1. 자산관리

#### 1.1. 고정자산
- 1.1.1. 자산관리
  - 자산관리 및 이관 → **팀장** ●결정
  - 재물조사 → **팀장** ●결정
- 1.1.2. 자산처각 품의(장부 또는 감정가액 기준)
  - 부동산:
    - 300,000 이하 → **본부장** ●결정
    - 3,000,000 이하 → **대표이사** ●결정
    - 3,000,000 초과, 200억원 또는 자기자본 2.5% 이하 → **대표이사** ●결정
    - 200억원 또는 자기자본 2.5% 초과 → **이사회** ●결정
  - 기타:
    - 10,000 이하 → **팀장** ●결정
    - 100,000 이하 → **본부장** ●결정
    - 300,000 이하 → **본부장** ●결정
    - 300,000 초과, 200억원 또는 자기자본 2.5% 이하 → **대표이사** ●결정
    - 200억원 또는 자기자본 2.5% 초과 → **이사회** ●결정

#### 1.2. 원재료, 제품, 자재 및 소모품 등
- 1.2.1. 재고관리 → **팀장** ●결정
- 1.2.2. 재고조정 및 제각품의(총조정 또는 제각금액 기준)
  - 1,000 이하 → **팀장** ●결정, 본부장 ○보고
  - 20,000 이하 → **본부장** ●결정
  - 20,000 초과 → **대표이사** ●결정

### 2. 세무관리
- 2.1. 제증빙서 발급
  - 2.1.1. 지급증
    - 50 이하 → **팀장** ●결정
    - 200 이하 → **본부장** ●결정
    - 200 초과 → **대표이사** ●결정
  - 2.1.2. 세금계산서 → **본부장** ●결정
  - 2.1.3. 기타영수증 → **팀장** ●결정

### 3. 회계관리

#### 3.1. 회계전표 작성 관리
- ※ 회계 상 거래의 ERP 전표 입력은 해당 조직의 장 책임으로 한다

- 3.1.1. 수입 회계전표 승인 → **팀장** ●결정
- 3.1.2. 지급 회계전표 승인
  - 사전 품의를 득하거나, 규정에 명기되어 있는 경우 → **팀장** ●결정
  - 사전 품의 또는 규정에 없는 경우:
    - 10,000 이하 → **팀장** ●결정
    - 10,000 초과 → **본부장** ●결정
    - 30,000 초과 → **대표이사** ●결정
    - 100,000 초과 → **대표이사** ●결정 (이상)
  - ※ 제반 법령에 의해 의무적으로 납부하는 비용 및 공공요금 → **팀장** ●결정
  - ※ 전결권자 본인 명의의 지출 비용은 차상위자의 승인을 득하여야 한다. 단, 차상위자가 일시적으로 부재인 경우 재무담당원의 확인 서명을 득한다.
  - ※ 대표이사, 감사, 사외이사의 지출비용은 재무담당원이 확인·서명한다.
  - ※ 고문의 지출 비용은 수행 업무, 소속 부서 등에도 불구하고 인력 담당 본부에서 상기 3.1.2에 따라 확인·서명한다.

#### 3.2. 전불 관리
- 3.2.1. 전불 신청 품의
  - ※ 등록된 거래처 및 계좌 지급이 원칙이나, 불가피한 경우에 한하여 사전 승인을 득한 후 전불 신청 가능
  - 10,000 이하 → **팀장** ●결정
  - 10,000 초과 → **본부장** ●결정
  - 30,000 초과 → **대표이사** ●결정
  - 100,000 초과 → **대표이사** ●결정

  - 경기 법인세 → **본부장** ●결정

    - 기타 → **팀장** ●결정

### 2. 결산
- 2.1. 결산보고
